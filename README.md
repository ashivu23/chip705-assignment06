# CHIP705 Assignment 06: Descriptive Statistics

## Description
This project analyzes patient demographic data and eGFR values.

The analysis focuses on patients with eGFR less than or equal to 65.

## Files
- assignment06_beginner.py: Main Python script
- main.ipynb: Jupyter Notebook analysis
- requirements.txt: Required Python packages
- patients_needing_screening.csv: Filtered patient data

## Requirements
Python 3 and the packages listed in requirements.txt.

## Installation
Run:

pip install -r requirements.txt

## Run the Python script
Run:

python3 assignment06_beginner.py

## Notebook
Open main.ipynb in Jupyter Notebook or Visual Studio Code and run the cells.

## Analysis
The project includes:
- Descriptive statistics
- Average eGFR by BMI category
- Patient age vs. eGFR scatter plot
- Patient sex distribution pie chart
